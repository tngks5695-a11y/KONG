# 힘 단위 변환기

Tkinter 기반의 데스크톱 GUI 프로그램입니다. 힘 값을 kN, N, kgf 사이에서 변환하고 변환 결과를 기록합니다.

## 기능

- 입력한 힘을 `kN`, `N`, `kgf` 중 선택한 단위로 변환합니다.
- 숫자 키패드 또는 키보드로 값을 입력하고, Enter 키로 변환할 수 있습니다.
- 단위 바꾸기 버튼으로 입력 단위와 출력 단위를 맞바꿀 수 있습니다.
- 변환 기록은 최신 결과부터 표시됩니다. 기록을 더블클릭하면 해당 값과 단위 선택을 다시 불러오며, 기록 지우기 버튼으로 기록 전체를 삭제할 수 있습니다.
- 초기화 버튼은 입력값과 단위를 기본값(`kN`에서 `N`)으로 되돌립니다. 종료 버튼은 프로그램을 닫습니다.

변환 기준은 `1 kN = 1000 N`, `1 N = 1 N`, `1 kgf = 9.80665 N`입니다. kgf 환산은 표준중력가속도 기준입니다.

## 필요한 환경

- Python 3
- Python 배포판에서 사용할 수 있는 `tkinter` 및 데스크톱 GUI 실행 환경
- 별도의 서드파티 Python 패키지는 코드에서 사용하지 않습니다.

## 실행 방법

터미널에서 `force_converter.py`가 있는 폴더로 이동한 뒤 실행합니다.

```bash
python3 force_converter.py
```

## 입력 예시

단위 버튼으로 입력 단위와 출력 단위를 선택한 뒤 값을 입력하고 **변환**을 누릅니다. 아래 예시에서 입력 단위는 `kN`, 출력 단위는 `N`입니다.

| 입력값 | 결과 |
| --- | --- |
| `2.5` | `= 2500 N` |
| `-1` | `= -1000 N` |
| `0.001` | `= 1 N` |

소수와 음수 입력이 가능합니다. 키보드로 직접 입력하거나 화면의 숫자 키패드를 사용할 수 있습니다.

## 오류 입력 예시

| 입력 | 표시되는 안내 |
| --- | --- |
| 빈 값 | `값을 입력해주세요.` |
| `abc` | `'abc' 은(는) 숫자가 아닙니다. 예: 12.5` |

오류는 디스플레이에 표시됩니다. 입력을 수정하거나 지운 뒤 다시 변환할 수 있습니다.

# CSV 하중 · 단면 응력 분석 GUI

`load_analyzer_gui.py`는 CSV에서 하중 데이터를 불러와 단면 형상을 선택하고, 단면적과 최대 응력을 계산해 그래프로 보여주는 Tkinter 프로그램입니다.

## 실행

프로젝트 폴더에서 실행합니다.

```bash
python3 load_analyzer_gui.py
```

화면의 **찾아보기** 버튼으로 CSV 파일을 선택합니다. CSV 첫 줄에는 `time_s`와 `force_N` 열이 있어야 합니다. 데이터가 유효하면 시간–하중 그래프와 유효/제외 행 수를 표시합니다. 단면 치수를 mm로 입력하고 **분석**을 누르거나 Enter/F5 키를 누르면 단면적(mm²), 최대 하중(N), 최대 응력(MPa), 최대 응력 발생 시간(s)과 시간–응력 그래프를 갱신합니다.

## 단면 형상과 계산식

| 형상 | 입력 치수 (mm) | 단면적 (mm²) | 유효 조건 |
| --- | --- | --- | --- |
| 사각형 | 폭 `b`, 높이 `h` | `b × h` | `b > 0`, `h > 0` |
| 원형봉 | 지름 `d` | `πd² / 4` | `d > 0` |
| 원형관 | 외경 `D`, 두께 `t` | `π[D² − (D − 2t)²] / 4` | `D > 0`, `t > 0`, `2t < D` |
| 사각형관 | 외측 폭 `B`, 외측 높이 `H`, 두께 `t` | `BH − (B − 2t)(H − 2t)` | 모든 치수 `> 0`, `2t < B`, `2t < H` |
| H형강 | 전체 높이 `H`, 플랜지 폭 `B`, 웨브 두께 `tw`, 플랜지 두께 `tf` | `2Btf + (H − 2tf)tw` | 모든 치수 `> 0`, `2tf < H`, `tw < B` |

응력은 `σ = F / A`로 계산합니다. 원형관과 H형강은 모서리 곡률과 필렛을 무시한 이상화 단면입니다. 계산에는 반올림 전 단면적을 사용합니다.

## 오류와 조건 변경

- 빈칸, 숫자가 아닌 값, 0, 음수 또는 형상별로 불가능한 치수는 안내하고 분석을 중단합니다.
- `time_s` 또는 `force_N`이 비어 있거나 숫자가 아니면 그 행만 제외하고 행 번호 및 문제 값을 표시합니다.
- 필수 열이 없거나 유효 데이터가 없으면 필요한 열 이름 또는 재확인 안내를 표시합니다.
- 원본 CSV는 읽기만 합니다. 새 CSV를 선택하면 기존 단면/응력 결과를 지웁니다.
- 단면 형상이나 치수를 바꾸면 기존 단면/응력 결과를 지우고 **조건 변경됨: 다시 분석 필요**를 표시합니다. 다시 분석하면 숫자와 그래프가 갱신됩니다.
- 그래프는 한 개의 축을 다시 그려 갱신하므로 분석을 반복해도 그래프가 겹쳐 쌓이지 않습니다.

## 실행 및 검증 예시

`load_data.csv`는 10개 유효 데이터이며 최대 하중은 5초의 800 N입니다. `load_bad.csv`는 빈칸과 `abc`가 있는 2개 행을 제외해 유효 데이터 8개로 처리합니다.

| 단면 | 입력값 | 단면적 (mm²) | 최대 응력 (MPa) |
| --- | --- | ---: | ---: |
| 사각형 | `b=10`, `h=10` | 100 | 8 (5 s) |
| 사각형 | `b=20`, `h=10` | 200 | 4 (5 s) |
| 원형봉 | `d=20` | 약 314.16 | 약 2.55 (5 s) |
| 원형관 | `D=40`, `t=5` | 약 549.78 | 약 1.46 (5 s) |
| 사각형관 | `B=40`, `H=60`, `t=5` | 900 | 약 0.89 (5 s) |
| H형강 | `H=100`, `B=80`, `tw=5`, `tf=8` | 1,700 | 약 0.47 (5 s) |

다른 CSV 복사본의 7초 하중을 900 N으로 바꾸면 사각형 `10 × 10 mm`에서 최대 응력은 9 MPa, 발생 시간은 7초입니다.

**분석 버튼은 선택한 CSV의 하중 데이터와 단면 치수로 응력 시계열과 최대값을 계산하고 결과 표시와 그래프를 갱신합니다.**

# CSV 하중 데이터 분석기

`load_analyzer.py`는 CSV로 기록된 하중(힘) 데이터를 읽어 통계와 응력을 계산하고, 그래프와 결과 CSV를 저장하는 프로그램입니다.

## 입력 열과 단위

- `time_s`: 시간 (초, s)
- `force_N`: 하중 (뉴턴, N)

첫 줄은 열 이름이며, 한 줄이 한 시점의 데이터입니다.

## 필요한 라이브러리

- Python 3 표준 라이브러리 (`csv`, `tkinter` 등)
- `matplotlib` (그래프를 PNG로 저장하는 데 사용, 별도 설치 필요: `python3 -m pip install matplotlib`)

## 실행 방법

```bash
python3 load_analyzer.py            # load_data.csv를 읽음 (기본값)
python3 load_analyzer.py load_bad.csv  # 다른 CSV 파일을 지정해 읽음
```

## 단면적 설정

응력(σ = F / A, 단위 MPa)을 계산할 단면적은 `load_analyzer.py` 상단의 `CROSS_SECTION_AREA_MM2` 상수(기본값 100 mm²)로 설정합니다. 값을 바꾸면 응력 계산과 그래프에 바로 반영됩니다.

## 출력 파일

- `load_result.csv`: `time_s`, `force_N`, `stress_MPa` 열을 담은 결과 파일 (원본 `load_data.csv`는 수정하지 않음)
- `stress_plot.png`: 시간-응력 그래프 (x축 Time (s), y축 Stress (MPa)), 최대 응력 지점을 빨간 점과 숫자로 표시

## 오류 처리 규칙

- `time_s` 또는 `force_N`이 빈칸이거나 숫자로 해석할 수 없으면 해당 행의 행 번호와 문제 값을 안내하고, 그 행을 계산과 그래프에서 제외합니다.
- 실행이 끝나면 제외한 행 수와 유효한 데이터 수를 출력합니다.
- 유효한 데이터가 하나도 없으면 계산을 멈추고 안내 메시지를 출력합니다.
- 원본 CSV 파일은 읽기만 하며 어떤 경우에도 수정하지 않습니다.
